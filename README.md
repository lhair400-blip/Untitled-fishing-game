# Untitled-fishing-game
a small pixel art fishing game.
Currently in development.

I am designing this game in order for me to get more comfortable with UI on Godot.
I am currently using Stardew valley as inspiration for my game as shown though the fishing mechanic and 2d top-down style

It currently doesn't have much going for it story / lore wise as i've just been focusing on getting the core mechanics down before I expand the game to fully fit a working story, but the basics of how the game will work will be fishing for fish then putting those fish into your aquarium where they will earn the player money which can be used to upgrade their fishing setup

The game has come a long way recently but there are still a bunch of features I would like to add and need to code as well as old features I really should fix and make better.

Currently most of the features within the game are tied to keybinds as I am mainly using it to test that everything works and eventually I will switch most of them over to an actual npc or object in game that makes much more sense for the feature to be attached to for example, the aquarium menu being activated by going up to an aquarium tank.

So far I haven't had much time to work on things like sprite work so most of the assets I have are free assets from itch.io but in the future I hope to be able to replace everything with my own assets. 

[Click here to play] (https://accurseddrifter.itch.io/untitled-fishing-game)

Current controls - 
  WASD - movement 
  Space - start fishing 
  Space - Reel in when fishing 
  I - Open / close inventory
  K - Open / close Sell menu
  J - open / close journal 
  L - Open / close aquarium menu
